# Budget app
An app for budgeting. 

## Technical info
### Expo App
The app is made with Expo: [https://docs.expo.dev/](https://docs.expo.dev/)

### Database
The data is stored in a Supabase database: [https://supabase.com/docs](https://supabase.com/docs)

### Sign-in
User sign-in is done with Supabase Authentication. 

## Structure
The plan is to have the following pages:
1. Home
   - Welcome Message
   - Pie Chart with the current budget > Money saved is green, money used is grey
   - Encouraging image e.g. a smiling sun, a growing plant etc
   - Add or Remove Money (button)
2. Budget overview
   - Table view
   - Add a Budget (button > form)
   - Edit a Budget (button > form)
   - Delete a Budget (button)
3. Income details
   - Add money (button > form)
   - Add money categories (button > form)
3. Notes
4. Settings
   - Change password, username etc
